# Example Note Flow

Use this flow only after `example-note` Step 0 passes.

## Inputs

- Title or topic.
- Intended audience.
- Key points or source notes.
- Optional tone, length, or output format.

## Steps

1. Restate the note goal in one sentence.
2. Identify missing inputs that block a useful draft.
3. Draft the note with a short title, compact body, and clear next action when
   one is implied.
4. Keep the output scoped to the requested note. Do not add repository changes,
   external posts, or broad workflow advice.

## Output

Return the drafted note and mention any missing assumptions only when they
materially affect the result.
