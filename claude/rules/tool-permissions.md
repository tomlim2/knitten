- **NEVER use bare `Bash`** in `allowed-tools` — Always specify patterns
- **Pattern examples:** `Bash(git:*)`, `Bash(python:*)`, `Bash(npm:*)`, `Bash(open:*)`, `Bash(mv:*), Bash(ls:*)`
- **Principle:** Grant the minimum permission that lets the command work
