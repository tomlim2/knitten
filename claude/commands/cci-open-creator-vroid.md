# Open VRoid Character Creator

Launch the VRoid Character Creator GUI for registering VRM characters without UE.

## Execution

1. Read `~/.claude/private/caol-config/repo-paths.json` → key `anju` → `.path`
2. Run:

```bash
python "<anju-path>\python\vroid_character_creator\vroid_creator_gui.py"
```
