Run the `learn-log-vocab` skill with the provided arguments.

## Arguments

$ARGUMENTS

## Behavior

- **Foreign text** → Detect language, analyze, translate, append to Obsidian
- **`review`** → Show summary of recent entries (default: this week, all languages)
- **`review japanese week`** → Filter by language and time period
- **`quiz`** → Random recall test from recent entries
- **No arguments** → Show usage
