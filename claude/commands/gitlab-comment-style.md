# GitLab Code Review Response Formatter

이전 대화에서 제공한 분석/답변을 GitLab MR 코드 리뷰에 대한 응답으로 변환합니다.

## 변환 규칙

### 톤과 스타일
- 코드 리뷰어에게 답변하는 형식
- 간결하고 명확한 기술적 설명
- 결론을 먼저, 근거는 그 다음

### 구조
1. **결론 먼저**: "변경 불필요", "수정 완료", "의도된 설계" 등
2. **근거**: 코드 흐름, 기술적 분석
3. **표**: 비교/정리가 필요한 경우 GitLab 테이블 사용

### GitLab 마크다운 형식
- 제목: `##` 헤더
- 코드: 언어 지정 코드 블록 (```cpp, ```python 등)
- 표: GitLab 호환 마크다운 테이블
- 강조: `**bold**` for 핵심 결론
- 구분선: `---`

## 작업

1. 이전 대화에서 가장 최근 분석/답변을 찾습니다
2. 코드 리뷰 응답에 적합한 톤으로 재작성합니다
3. GitLab MR 코멘트로 바로 복사-붙여넣기 할 수 있는 형식으로 출력합니다

## 출력 형식 예시

```
## 분석 결과: [결론]

### [이슈 제목]

[핵심 설명]

| 항목 | 내용 |
|------|------|
| ... | ... |

→ [최종 결론/액션]
```
