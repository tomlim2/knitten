# learn-browse-entries

Web-based viewer for project learnings stored in private/learnings/.

## Purpose

Provide a web UI to browse and view project-specific learnings, conventions, and gotchas.

---

## Features

- Browse projects with learnings
- View conventions, gotchas, and notes
- Full markdown rendering (headings, paragraphs, bullets, tables, code blocks, inline code)
- Code styling compliant with Design System v1.6.1 Code Blocks pattern

## Usage

Access via skill-server dashboard or directly at `/skills/learnings-viewer`.

## Files

Served through skill-server at `/skills/learnings-viewer`. No standalone files.
