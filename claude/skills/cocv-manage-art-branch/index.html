Art Dashboard

CINEV art 브랜치 관리 워크플로우 대시보드

BRANCH NAMING
art/<art-versioning>, art/merge/<art-versioning>
CONFIG
~/.claude/config/slack.json
REQUIRED
SLACK_TOKEN, SLACK_ART_CHANNEL

Workflow

  • 1. Create Art Branch /cocv-manage-art-branch create
  • 2. Merge Notice /cocv-manage-art-branch merge-notice
  • 3. Prepare Merge /cocv-manage-art-branch merge-prep
  • 4. Merge Result /cocv-manage-art-branch merge-result
  • 5. Cleanup /cocv-manage-art-branch cleanup

Commands

  • /cocv-manage-art-branch 통합 관리 (자동 제안)
  • /cocv-manage-art-branch status 상태 확인
  • /cocv-art-send-notice 일반 Slack 알림
