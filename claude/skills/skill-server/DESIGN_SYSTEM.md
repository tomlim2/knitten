## Typography

### Font Families (2)

| Token | Value |
|-------|-------|
| Sans | 'Noto Sans KR', sans-serif |
| Mono | 'JetBrains Mono', monospace |

### Type Scale (4 sizes)

| Size | Usage |
|------|-------|
| 12px | Labels, meta, captions, buttons, code |
| 16px | Body text, inputs, nav, card names |
| 24px | Headings, hero name, related cards |
| 36px | Display (hero mono) |

| Role | Size | Font | Weight |

| Body | 16px | Sans | 400 |

| Heading | 24px | Sans | 500 |
| Display | 36px | Mono | 400 |
| Code | 12px | Mono | 400 |
| Button | 12px | Sans | 600 |
