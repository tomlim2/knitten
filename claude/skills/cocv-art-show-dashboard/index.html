Art Dashboard

CINEV art 브랜치 관리 워크플로우 대시보드

BRANCH NAMING
art/<art-versioning>, art/merge/<art-versioning>
CONFIG
~/.claude/config/slack.json
REQUIRED
SLACK_TOKEN, SLACK_ART_CHANNEL

Workflow

  • 1. Create Art Branch /cocv-art-create-branch
  • 2. Send Notice /cocv-art-send-notice
  • 3. Prepare Merge /cocv-art-prepare-merge
  • 4. Merge Notice /cocv-art-send-merge-notice
  • 5. Merge Result /cocv-art-send-merge-result
  • 6. Remove Old Branch /cocv-art-remove-branch

Commands

  • /cocv-art-create-branch 브랜치 생성
  • /cocv-art-send-notice Slack 알림
  • /cocv-art-prepare-merge 머지 준비
  • /cocv-art-send-merge-notice 머지 알림
  • /cocv-art-send-merge-result 완료 알림
  • /cocv-art-remove-branch 구 브랜치 정리
