# STL-326 closed — BuildKit cache + Containerfile builder polish

## 11:30 — STL-326 closed ([#261](https://github.com/CINEV/shotloom/pull/261))

`hon454` round 1 리뷰 5개 finding → 당일 대응 → 머지. 상세 공부 노트는 [[2026-05-08-pr-261-review-round1-cicd-study]] 참고.

**지적 1 — wasm-pack tarball SHA-256 검증 없음 (Blocking).** `curl | tar` 패턴은 integrity 미검증 — stealth re-tag 공격면. → `sha256sum -c -` 검증 + digest ARG 핀 (`8c8a471`).

**지적 2 — x86_64 하드코딩 무코멘트 (Should).** 다른 arch runner 추가 시 404로 silent fail. → "x86_64-only by design" 코멘트로 loud-fail 보장.

**지적 3 — pipefail 미설정 (Low).** `sh` 기본값 pipefail off → 파이프 중간 실패가 마지막 exit code에 묻힘. → `SHELL ["/bin/bash", "-o", "pipefail", "-c"]`.

**지적 4 — corepack 노출 안 한 이유 코멘트 누락 (Nit).** → "intentionally NOT exposed" 코멘트.

**지적 5 — no-cache 코멘트에 jump-off 없음 (Nit).** → run ID + Linear 이슈 번호 박음 (H8 룰 충돌 → 사용자 판단으로 리뷰어 우선).

> [!tip] build infra PR은 사전 체크리스트 없으면 round 1에서 깎인다
> `curl | tar` → SHA256, pipefail, arch 코멘트. 이 세 가지가 `review-rust.md`에 없고 별도 build-infra 가이드라인도 없음 — 다음 Containerfile 작업 전 체크리스트 추가할 것.

> [!abstract] Rule
> Containerfile 외부 binary 설치 체크리스트: ① digest 핀 + sha256sum 검증, ② `SHELL pipefail`, ③ arch 하드코딩 코멘트. 세 가지 빠지면 round 1 CHANGES_REQUESTED 확정. #rule
