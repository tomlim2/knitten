# STL-346 closed — rustdoc intra-doc link fix

## 11:10 — STL-346 closed ([#272](https://github.com/CINEV/shotloom/pull/272))

단일 파일, 한 문자쌍 수정 (`` [`…`] `` → `` \[`…`\] ``). PR이 uneventful하게 머지됨 — CI 전부 그린, 리뷰 라운드 없음.

회고할 지적 없음. 이 PR의 유일한 교훈은 **rustdoc이 `` [`…`] `` 를 intra-doc link로 파싱한다는 것** — Rust item 이름이 아닌 파일 경로를 backtick-bracket으로 감싸면 `warning: unresolved link`가 누적됨. 다음에 doc comment에서 파일 경로 참조할 때는 `\[` escape 또는 backtick-only (`` `path` ``) 사용.

> [!abstract] Rule
