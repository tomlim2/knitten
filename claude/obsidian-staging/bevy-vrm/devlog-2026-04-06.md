# 2026-04-06: Finger Bind Pose Fix

### 왜 이 작업을 했나

Standing FBX에서 finger bone direction이 FBX와 안 맞음. verify avg=27.5°, worst=63.1°. finger correction이 있었지만 여러 버그로 제대로 동작 안 함.

### 한 일

**Bug 1: Duplicate hand in FK chain**
- `chain_to_hips("rightHand")` already includes hand, but code pushed it again
- Double hand rotation in FK evaluation

**Bug 2: Coordinate space mismatch**
- `fbx_local = parent_world⁻¹ * fbx_dir` → parent frame
- `vrm_local_dir` (child rest_translation) → bone's own frame
- Fixed to use `bone_world⁻¹ * fbx_dir`

**Bug 3: Verify chain incomplete**
- `[hips,...,hand, Intermediate, Distal]` — Proximal missing
- FK position wrong for seg_idx > 0

**Bug 4: Static threshold too tight (0.5° → 2.0°)**
- Standing FBX finger bones had 1° jitter → classified as "animated" → skipped
- 9 out of 20 bones not corrected due to this

> [!tip] Static threshold was THE primary bug
> 4개 버그 중 이것만 고쳐도 11→20 bones corrected. 나머지는 정확도 개선.

**Bug 5: Bevy vs FK convention mismatch**
- FK: `parent * rest⁻¹ * local`, Bevy: `parent * local`
- Hips 7° rest → hand_world 7° off → finger curl plane shifted
- Front view correct, side view fingers bent upward
- Fixed finger correction to use Bevy convention throughout

> [!warning] FK convention ≠ Bevy convention
> `eval_fk_chain_bones` uses glTF FK. Bevy uses `parent * local`. 차이가 root bone rest rotation만큼 누적됨. See [[bevy-vrm/learning-bevy-fk-convention]]

**Metacarpal fold (실험, disabled)**
- Non-thumb fingers: FBX 4 bone vs VRM 3 bone
- Tried using FBX Metacarpal→Intermediate direction for Proximal correction
- avg=4.3° but cascading effect on Intermediate → disabled pending further work
- Experiment logged in experiments-finger-metacarpal-fold.md

**Viewer improvements**
- Auto mesh hidden on startup
- Gizmo sphere size reduced (0.005→0.0025)

### 배운 것

**Bevy FK convention** — retarget output은 Bevy의 `Transform::rotation`에 직접 적용되도록 설계됨. FK formula(`rest⁻¹`)를 쓰면 root rest rotation이 누적되어 visual mismatch.

**Static threshold sensitivity** — 0.5° threshold가 standing FBX의 1° numerical jitter를 "animated"로 판정. 가장 큰 impact.

**Verify chain completeness** — Intermediate verify 시 Proximal을 chain에 포함해야 FK position이 정확.

**finger_bind는 Thumb만** — retargeter의 three-quat formula가 이미 non-thumb finger curl을 처리함. finger_bind를 4-finger에 적용하면 이중 교정 → over-curl. Thumb만 bind pose correction 필요 (retargeter가 thumb curl을 안 함).
