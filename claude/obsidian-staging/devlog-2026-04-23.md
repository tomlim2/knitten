## 데모 composition

1080×1920 세로 포맷, 노랑 계열, "Today is Thursday Apr 23 2026" 바운스 스케일 애니메이션.

**핵심 패턴**:

- 모든 timed element에 `data-start` / `data-duration` / `data-track-index` + `class="clip"`
- GSAP timeline은 `paused: true` + `window.__timelines["composition-id"]`에 등록
- CSS `transform: translate(-50%, -50%)` + GSAP `y` 병행 금지 — 대신 `gsap.set({ xPercent: -50, yPercent: -50 })` 사전 적용 후 `fromTo`에서 유지
- 바운스: `back.out(2.2~2.6)` easing + `scale: 0.3 → 1`
- Deterministic 폰트만 사용 (`Inter`, `Montserrat` 등) — `SF Pro Display` 같은 미매핑 폰트는 폴백됨

**Lint는 필수**: `npx hyperframes lint` 0 errors가 완료 기준.

## 오디오 테스트 — API 없이

`npx hyperframes tts`는 로컬 Kokoro-82M ONNX 모델 씀 → API 키 불필요. 근데 `pip install kokoro-onnx soundfile` 의존성 충돌로 이번엔 못 씀.

**대안**: macOS 빌트인 `say` + `ffmpeg` 변환.

```bash
say -v Samantha -o assets/narration.aiff "Today is Thursday, April 23rd, 2026"
ffmpeg -y -i assets/narration.aiff assets/narration.wav
```

composition에 `<audio id="narration" class="clip" data-start="0.3" data-duration="3.7" data-track-index="6" src="assets/narration.wav"></audio>` 추가.

**주의**: `<audio>`는 `id` 속성 필수 — 없으면 lint가 `media_missing_id` error 뱉고 렌더 시 SILENT 됨.
