# Honest Caveat (정직한 단서)

**Date:** 2026-04-14

## 핵심

**Caveat = "미리 알려두는 경고나 단서".** 라틴어 *cavēre*(조심하다)에서
옴. 직역하면 "주의하라(let him beware)".

**"이건 좋은데, 단 ___" 의 그 ___ 부분.** 어떤 주장/제안/결과를 말할 때
"이런 한계나 조건이 있으니 알고 써라"라고 미리 까는 것.

## "Honest caveat"의 뉘앙스

자기 작업의 한계를 **숨기지 않고 드러내는** 단서. 마케팅이나 자랑할 때
불리한 부분을 일부러 표시하는 것 = 신뢰의 표현.

반대편:
- **숨김** — 한계 말 안 함 → 나중에 들킴 → 신뢰 폭락
- **과장된 caveat** — 책임 회피용 면피 ("작동 안 할 수 있음")
- **묻힌 caveat** — 작은 글씨, 각주, 안 읽는 곳

**Honest caveat = 눈에 띄게, 구체적으로, 행동 가능한 형태로 적는 단서.**

## 비슷한 단어와의 차이

| 단어 | 뉘앙스 |
|---|---|
| **caveat** | "이건 알고 써라" — 중립, 정보 제공 |
| **disclaimer** | "법적 면피" — 책임 회피 톤 |
| **warning** | "위험하다" — 강한 경고 |
| **limitation** | "이건 못 함" — 능력의 한계 |
| **assumption** | "이걸 전제로 함" — 조건 |
| **footnote** | "부가 정보" — 약함, 잘 안 읽힘 |

## 좋은 vs 나쁜 caveat

### ❌ 나쁨 (의미 없음)
> "이 코드는 작동 안 할 수도 있습니다."

### ❌ 나쁨 (숨김)
> *문서 맨 아래 작은 글씨로*: "성능은 환경에 따라 다를 수 있습니다."

### ✅ 좋음 (정직한 caveat)
> "FK-only 리타겟입니다. **Caveat**: 발 sliding이 있는 클립은 후처리
> 필요. 소품 잡기는 지원 안 함. 디스플레이 용도엔 충분합니다."

= 한계가 명확 + 구체적 + 어떤 케이스에 문제 되는지 + 사용자가 자기
케이스에 맞는지 판단 가능.

## 왜 정직한 caveat이 중요한가

**Trust currency.** 자기 한계를 먼저 까는 사람이 결과적으로 신뢰를 더 얻음.

1. **나중에 들킬 일 없음** — 미리 말했으니까
2. **사용자가 제대로 판단** — 잘못된 케이스에 안 씀
3. **도와줄 사람 생김** — 한계가 명확하면 누군가 보완
4. **자기 검증 신호** — "한계를 안다" = "뭘 모르는지 안다" = 메타인지

반대로 한계 숨기면:
- 한 번은 통과하지만 두 번째부터 안 통함
- "그때 왜 말 안 했냐"로 신뢰 폭락
- "다 안다는 척"이라 진짜 도움 못 받음

## 리타겟/shotloom 맥락 — 실전 예

```
⚠️ 현재 한계
• 소품 잡기 ❌
• 벽 짚기, 상호작용 ❌
• 가파른 경사/계단에서 발 sliding 가능성
• 여러 캐릭터 간 상호작용 ❌

→ shotloom 용도가 "AI 모션 디스플레이"라면
   위 한계들은 실제로 문제 되지 않을 가능성이 큽니다.
```

honest caveat의 교과서 형태:
1. **구체적** (뭐가 안 되는지 명시)
2. **눈에 띔** (별도 섹션, 이모지)
3. **맥락 제공** ("이 용도엔 문제 없다" 판단 도움)

## 코드 문서에서의 caveat 패턴

```rust
/// Retargets FBX motion onto VRM character.
///
/// # Caveats
/// - Does NOT handle prop interaction (no hand IK)
/// - Foot sliding may occur on slopes > 30°
/// - Assumes T-pose source rest
/// - Single-character only — no multi-actor scenes
pub fn retarget(...) -> Result { ... }
```

Rust doc comment의 `# Caveats` 섹션은 표준 관행.

## 한 줄

**정직한 caveat = 자기 한계를 숨기지 않고 구체적으로 드러내는 행위.**
신뢰 자본을 쌓는 가장 효율적인 방법. 디스클레이머와 달리 **회피용이
아닌 정보 제공용**. 좋은 엔지니어/디자이너의 공통 습관.
