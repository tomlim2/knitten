# Entanglement (얽힘)

**Date:** 2026-04-13

## 핵심

**"혼합 가능"이 아니라 "얽혀서 분리가 안 되는 상태"**.
실타래가 꼬여서 풀 수 없는 상태를 떠올리면 정확함.

어원: **en-** (안으로) + **tangle** (엉킴) = "엉켜버림"

## 분야별 의미

| 분야 | 뜻 |
|---|---|
| **일상어** | 얽힘, 연루됨 ("legal entanglement" = 법적으로 엮임) |
| **양자역학** | 양자 얽힘 — 두 입자 상태가 연결돼서 하나를 측정하면 다른 하나가 즉시 결정됨 |
| **소프트웨어** | 두 모듈이 서로 너무 의존해서 따로 수정/분리 불가능한 상태 |

## 혼동하기 쉬운 단어들 (중요)

| 단어 | 뜻 | 좋음/나쁨 |
|---|---|---|
| **entanglement** | 얽힘 — 분리 어려움 | ❌ 나쁨 |
| **coupling** | 결합도 — 의존 관계 | ⚠️ 정도 문제 |
| **blending** | 섞기 — 의도적 혼합 | ✅ 좋음 |
| **integration** | 통합 — 하나로 합침 | ✅ 좋음 |
| **composition** | 조합 — 조립 가능 | ✅ 좋음 |

"섞인다/합친다"는 의미로 쓸 땐 `blending`, `composition`, `integration`
중에서 고르는 게 맞음. `entanglement`는 거의 항상 부정적 맥락.

## 리타겟/코드 맥락 예시

- **"검증기와 픽스처가 entangled"** = 둘이 얽혀서 한쪽만 고치면 다른 쪽이 깨짐
  → 바로 "검증기 오염"이 이 상태. Rubric A/B/C를 분리한 이유가 이걸 피하려는 것.
- **"Pass 1과 Pass 2가 entangled 되지 않도록"** = 분리된 레이어로 유지
- 반대로 **"FK pipeline은 well-composed다"** = 깔끔하게 조합돼 있음 ✅

## 한 줄

**entanglement = 나쁜 의미의 "얽힘".** 개발 맥락에선 거의 항상
"피해야 할 상태"를 가리킴. 혼합/조합을 표현하려면 다른 단어를 써야 함.
