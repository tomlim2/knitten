# Contradiction (모순)

**Date:** 2026-04-13

## 핵심

**서로 반대되는 두 주장이 동시에 참일 수 없는 상태.**
한국어 "모순(矛盾)"과 정확히 같은 개념 — 창(矛)과 방패(盾) 고사.

어원: **contra-** (반대) + **diction** (말하기) = "반대로 말함"

## 분야별 의미

| 분야 | 뜻 |
|---|---|
| **논리학** | `P ∧ ¬P` — 명제와 그 부정이 동시에 참 (불가능) |
| **일상어** | 말이 앞뒤가 안 맞음, 자기모순 |
| **수학/증명** | 귀류법(proof by contradiction) — 반대 가정 → 모순 도출 → 원래 명제 증명 |
| **소프트웨어** | 두 요구사항/제약이 동시에 만족 불가능 |

## 혼동하기 쉬운 단어들 (중요)

| 단어 | 뜻 | 강도 |
|---|---|---|
| **contradiction** | 모순 — 논리적으로 양립 불가능 | 🔴 가장 강함 |
| **conflict** | 충돌 — 해결 가능한 대립 | 🟡 조정 가능 |
| **inconsistency** | 불일치 — 일관성 없음 | 🟡 고치면 됨 |
| **paradox** | 역설 — 모순처럼 보이지만 사실은 참 | 🟢 흥미로움 |
| **tension** | 긴장 — 대립이 있지만 공존 가능 | 🟢 건강할 수도 |

## Paradox와의 차이

- **Contradiction** = 진짜 논리적 불가능. 반드시 둘 중 하나는 거짓.
- **Paradox** = 모순처럼 "보이는" 것. 깊이 보면 해소됨.

예:
- "이 소프트웨어는 빠르고 느리다" → contradiction (뭔가 잘못된 주장)
- "Python 코드가 C 코드보다 빠를 수 있다" → paradox (알고리즘 차이로 실제 가능)

## 리타겟/코드 맥락 예시

- **"FK-only가 foot sliding을 완벽히 막는다"** ↔ **"AI 모션은 foot sliding이 고질병이다"**
  → Contradiction. 그래서 "FK로 80% 커버, 나머지는 후처리"로 타협.

- **"rubric A는 소스만 평가"** ↔ **"rubric A에서 retarget 결과 참조"**
  → 설계 원칙 vs 구현 contradiction → 리팩터 신호.

- **"검증기 수정과 픽스처 수정을 같은 PR에서 하지 않는다"** 원칙:
  → 두 변경이 서로의 오라클이 되면 **contradiction이 숨겨짐**. 그걸 방지.

## 한 줄

**Contradiction = 동시에 참일 수 없는 두 주장.** 개발에선 "설계 원칙 vs
실제 구현"이 어긋났을 때, 또는 "두 요구사항이 논리적으로 양립 불가"일 때
쓰는 가장 강한 단어. 그냥 "안 맞음"은 `inconsistency`, 해결 가능한 대립은
`conflict`로 구분해서 쓰면 정확함.
