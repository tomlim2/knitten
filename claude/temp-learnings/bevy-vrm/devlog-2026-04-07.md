# 2026-04-07: Finger Muscle-Space Retarget

### 왜 이 작업을 했나

Three-vrm formula의 `parentRestWorld`에 FBX arm A-pose가 포함되어 finger curl axis가 60-90° 틀어지고, animated finger가 뒤로 꺾이는(backward curl) 문제. 어제 세션에서 world-space delta를 시도할 예정이었음.

### 한 일

**Phase 1: Hand rebasis conjugation**
- Position-based hand orientation(forward + palm normal) → `rebasis = vrm_orient × fbx_orient⁻¹`
- Three-vrm 결과를 `rebasis × result × rebasis⁻¹`로 conjugation
- Axis error 60-90° → 10-17° 개선, magnitude 100% 유지
- 하지만 animated finger가 여전히 backward (Z-sign flip)

**Phase 2: Backward 원인 분리 (Experiment A-H)**
- A-E: rebasis 변형 (direction only, convention palm, slerp, proximal only, no swing-twist) → 전부 6 backward
- F: no rebasis → 4 backward (Intermediate only)
- H: no rebasis, no dst_rest → 4 backward
- **결론: backward는 three-vrm `parentRest` conjugation 자체 + IK2 hand correction 합작**

> [!tip] Pre-IK2 vs Post-IK2 backward 비교로 원인 분리
> Pre-IK2: 3 (borderline Z≈-0.14), Post-IK2: 6 (severe Z≈-0.75). IK2가 주 악화 요인.

**Phase 3: Muscle-space curl retarget**
- FBX에서 curl angle(스칼라) 추출 → VRM curl axis에 재적용
- `curl_axis = palm_normal × bone_direction` (non-thumb)
- `swing_twist(delta, fbx_curl_axis)` → twist = curl component → VRM axis에 적용
- **Backward: 6 → 0 양손 전부 해결**

> [!tip] Curl을 스칼라로 추출해서 올바른 축에 재적용하면 coordinate frame 독립
> FBX curl axis에서 angle 추출, VRM curl axis에 적용. A-pose/T-pose/IK2 hand 전부 무관.

**Phase 4: Thumb 별도 처리**
- `palm_normal × thumb_dir`이 degenerate (둘 다 -Y 방향, 거의 평행)
- Rebasis도 thumb Z를 뒤집음 (thumb bone axis가 -Y라서)
- **Codex 제안**: hand radial axis (index→pinky 방향) 사용
  - `thumb_curl_axis = thumb_dir × reject(hand_radial, thumb_dir)`
- Thumb Proximal/Distal에 적용, Metacarpal은 rebasis 유지
- rightThumbProximal rest: 22.7° → **0.1°**

> [!warning] Thumb은 다른 finger와 같은 공식 사용 불가
> Palm normal과 thumb direction이 평행 → cross product degenerate. Hand radial axis가 해법. #gotcha

**Phase 5: DOF constraints**
- Non-thumb: X-twist 제거 (all fingers)
- Thumb: X-twist 제거 제외 (bone axis가 ±X 아님)
- Intermediate/Distal: splay 제거 시도 → backward 해결에 효과 없음 (local vs world 불일치)

### 배운 것

**Three-vrm backward curl은 parentRest conjugation + IK2 hand 합작**
parentRest가 arm A-pose를 포함하고, IK2가 hand를 회전시키면 finger FK chain 전체의 world direction이 뒤집힘. Local rotation 조작으로는 world backward 해결 불가.

**Muscle-space (scalar curl) 방식이 유일한 해결책**
Curl angle을 스칼라로 추출하면 coordinate frame에 독립적. FBX axis에서 추출, VRM axis에 적용. Three-vrm/rebasis/IK2 전부 우회.

**Thumb은 hand radial axis가 필요**
`palm_normal × bone_dir` 공식은 bone이 ±X 방향일 때만 안정적. Thumb(-Y)은 hand radial(index→pinky)을 대신 사용.

**CLI backward detection으로 실험 효율 10배**
`finger-diag`의 Z-sign flip detection으로 viewer 없이 backward 확인. Pre/Post IK2 비교로 원인 분리.
