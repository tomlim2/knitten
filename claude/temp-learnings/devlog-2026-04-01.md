# Day 3 (04-01): IK full-body FK evaluator + hand rotation + right finger curl fix

### 왜 이 작업을 했나

R-027 handoff: IK solver math는 정확하지만 viewer에서 팔이 여전히 뒤로 젖힘. `compute_chain_world()`가 shoulder parent를 rest pose로 근사하여 animated spine rotation이 무시됨. 이후 hand rotation과 finger curl 방향 문제도 연쇄적으로 발견.

---

## 한 일

### 1. Full-body FK evaluator (commit `0992a2a`)

**문제:** `compute_chain_world()`가 `[shoulder, upper, lower, hand]`만 평가 → shoulder parent(upperChest)는 rest pose 근사 → animated spine 무시

**해법:** `build_chain_to_hips()` — parent_map으로 bone에서 hips까지 올라가 전체 chain 구성
- `[hips, spine, chest, upperChest, shoulder, upper, lower, hand]` 전신 FK chain
- hips parent = root_bone(static) → rest pose 사용 정확
- IK error: 8.4cm → 0.5cm avg

> [!tip] FK evaluator가 정확해야 IK도 정확
> IK solver math가 맞아도 parent world transform이 틀리면 결과가 틀림. Rest pose 근사는 static bone(root)에만 허용.

### 2. Hand rotation correction 시도 및 철회 (commit `d1c70df`, `2f5492c`에서 제거)

3가지 접근 시도:
1. **FBX world-space delta** → VRM 0.x에서 15° 잔여 오차 (basis change 문제)
2. **FK world rotation 보존** → 개념적으로 잘못됨 (FK world도 부정확)
3. **Parent-relative delta** → 수치상 0° 달성, viewer에서 "바깥으로 구부러짐"

> [!warning] World-space delta vs parent-relative delta
> A-pose↔T-pose 팔 방향 차이 때문에 world delta를 VRM rest에 직접 적용하면 방향이 틀어짐. Parent-relative가 이론적으로 맞지만 coord_rot 변환에서 추가 문제 발생. 재설계 필요.

**현재 상태:** hand rotation correction 제거됨 (TODO)

### 3. Right finger curl inversion fix (commit `2f5492c`)

**문제:** Right hand finger가 반대로 curl됨
- FBX raw: rightIndex Z축 = +0.99
- Retarget 결과: Z축 = -0.88 (반전!)

**원인:** retarget formula `parent_rest_yup × anim_local × bone_rest_yup⁻¹`에서 right side parent_rest가 mirroring되어 Z축 반전

**해법:** right finger bone에 `result = result.conjugate()` 적용 (curl 방향 반전 보정)
- rightIndex Z: -0.88 → +0.85 ✅
- rightMiddle Z: -0.98 → +0.97 ✅

### 4. Finger motion diagnostics 추가

headless CLI에 finger bone rotation 분석 출력:
- frame 0 vs 최대 변화 frame 비교
- Rotation axis/angle + FBX raw 비교
- t2m FBX에는 finger animation 없음 확인 (body-only generation)

### 5. Sitting FBX 문제 발견 (미해결)

`female_sitting.fbx`에서 VRM이 앉지 못함:
- FBX hips Y=0.570 (앉아있음), VRM은 0.910 (서있는 rest) 그대로
- 원인: `motion_delta = frame[i] - frame[0]`에서 frame 0 자체가 이미 앉은 상태 → delta=0
- 해결 필요: skeleton bind pose(T/A-pose)를 rest로 써야 함

---

## 배운 것

**VRM 0.x basis change `(-x,y,-z,w)`는 right side bone에서 curl 축을 반전시킨다.** Left는 우연히 부호가 맞지만 right는 Z축이 뒤집힘. Conjugate로 보정.

**Hand rotation correction은 좌표계 변환이 핵심.** World-space delta, FK preservation, parent-relative delta 3가지 시도했으나 각각 다른 문제. 정확한 접근은 retarget pipeline과 동일한 space에서 작업하는 것.

**Source FBX에 데이터가 없으면 retarget도 없다.** t2m(text-to-motion)은 body motion만 생성, finger animation은 상수. 버그가 아님.
