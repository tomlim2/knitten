# 오늘의 단어 — 2026-04-13

## 오라클 (Oracle)

소프트웨어 테스트 용어. **"이 결과가 맞는지 틀린지 판정해주는 기준"** = 정답지 역할.

### 종류
- **자동 오라클**: 단위 테스트의 `assert expected == actual` — 기대값이 오라클
- **골든 파일 오라클**: 이전에 저장해둔 "정답 출력"과 비교
- **사람 오라클**: 사람이 눈으로 보고 "맞다/틀리다" 판정

### 맥락
리타겟/애니메이션 검증에서 "최종 오라클은 사람 눈 + 뷰어 재생"이라는 말은:
자동 검증(스코어, 메트릭, diff)은 전부 드리프트하거나 오염될 수 있으니,
**최종 정답 판정권은 사람이 뷰어로 직접 보는 것**에 있다는 뜻.

JS 비유: `expect(x).toBe(y)`의 `y`가 오라클. 리타겟처럼 "수치상 맞지만
눈으로 보면 이상한" 도메인에서는 수치 오라클을 못 믿으니 사람 눈이
최종 오라클이 된다.
