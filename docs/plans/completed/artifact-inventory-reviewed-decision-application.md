# Artifact Inventory Reviewed Decision Application

## Purpose

Apply reviewed artifact classification decisions to the generated inventory so
later pack migration specs can consume machine-readable decisions instead of
only Markdown reports.

## Problem

`core-artifact-boundary` has a reviewed first batch report for 125 core-owned
rows, but `agent/config/artifact-inventory.json` still emits almost every row as
`classification-stage: undecided` and `proposed-destination: undecided`.

Baseline count before this implementation:

| Metric | Count |
|--------|-------|
| total rows | 763 |
| `classification-stage: undecided` | 760 |
| `classification-stage: core-candidate` | 0 |
| `classification-stage: pack-candidate` | 0 |
| `classification-stage: migrate-later` | 3 |
| `review-state: accepted` | 6 |
| `review-state: blocked` | 10 |
| `review-state: pending` | 747 |

Post-implementation count after regeneration:

| Metric | Count |
|--------|-------|
| total rows | 799 |
| `classification-stage: undecided` | 696 |
| `classification-stage: core-candidate` | 95 |
| `classification-stage: pack-candidate` | 5 |
| `classification-stage: migrate-later` | 3 |
| `review-state: accepted` | 6 |
| `review-state: blocked` | 10 |
| `review-state: pending` | 783 |

The migration plan cannot safely select core, private-pack, or migrate-later
rows until reviewed decisions are encoded in generated inventory.

## Goals

| Goal | Acceptance |
|------|------------|
| Apply reviewed decisions. | Rows in `core-owned-classification-2026-05-24.md` are emitted with reviewed `classification-stage`, `proposed-destination`, and blocker state. |
| Preserve generator ownership. | Decisions are generated by `scripts/generate-artifact-inventory.mjs`, not hand-edited into `agent/config/artifact-inventory.json`. |
| Keep blockers explicit. | Blocked, command-retirement, and public-safety rows stay `migrate-later` or `undecided` exactly as the report says. |
| Prove count delta. | Validation records before/after counts for undecided, core-candidate, pack-candidate, migrate-later, accepted, blocked, and pending rows. |
| Avoid migration. | No skill, rule, standard, config, script, or doc files move. |

## Proposed Design

### Decision Source

Use the reviewed report as the canonical owner for this slice:

```text
docs/plans/reports/core-artifact-boundary/core-owned-classification-2026-05-24.md
```

Encode the report's row decisions in
`agent/config/artifact-inventory-reviewed-decisions.json`. The generator applies
the data to currently emitted row ids. The validator permits decision rows whose
source files no longer exist because command retirement and path cleanup already
removed several old rows.

### Decision Fields

| Report field | Inventory field |
|--------------|-----------------|
| `Stage` | `classification-stage` |
| `Destination` | `proposed-destination` |
| `Blocker` not `none` | keep or set `review-state: blocked` only when the reviewed report says the row is blocked |
| `Blocker` is `command-retirement-plan` | `classification-stage: migrate-later`, `proposed-destination: migrate-later` |
| `Destination` is `undecided` due public safety | keep `proposed-destination: undecided` and record the row in validation evidence |

### Validation Additions

Add or extend validator coverage so reviewed rows cannot silently regress to
`undecided` after the generator changes.

| Check | Failure |
|-------|---------|
| Reviewed row id source exists but row is missing from generated inventory. | `reviewed decision row missing` |
| Reviewed row emits a different stage or destination than the decision map. | `reviewed decision mismatch` |
| Reviewed blocked row emits `accepted`. | `blocked reviewed row marked accepted` |

## Risks

| Risk | Control |
|------|---------|
| Markdown report and generator map diverge. | Validator checks mapped reviewed row ids and expected fields. |
| Report decisions are over-applied to unreviewed rows. | Only row ids listed in the reviewed report are mapped. |
| Blocked rows become migration-ready by accident. | Preserve blocker rows as `blocked`, `migrate-later`, or `undecided` according to report evidence. |
| Physical migration starts too early. | This spec forbids file moves outside generated inventory and validator edits. |
