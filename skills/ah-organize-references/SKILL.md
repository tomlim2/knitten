# AH Organize References

Use this leaf skill after references have been gathered and need to be made
usable for spec or review work.

## Input

- Raw references, notes, links, or excerpts.

## Output

- Grouped reference summary.
- Relevant facts.
- Discarded noise.
- Open questions.

## Steps

1. Group references by purpose, such as policy, existing implementation,
   examples, validation, or prior decisions.
2. Keep only task-relevant facts.
3. Mark contradictions or unclear assumptions.
4. Produce a concise summary suitable for a spec or review.
