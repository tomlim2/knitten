# AH Brainstorm Approaches

Use this leaf skill when there are meaningful ways to solve the task and the
choice affects implementation shape.

## Input

- Task purpose.
- Reference summary.
- Constraints or user preferences.

## Output

- Viable options.
- Tradeoffs.
- Recommended direction.
- Rejected options with brief reasons.

## Steps

1. Identify two or three realistic approaches.
2. Compare scope, risk, validation, and maintainability.
3. Choose the smallest approach that satisfies the task.
4. Preserve open questions when the choice requires user judgment.
