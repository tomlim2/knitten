# Metaphor style — kitchen or orchestra

When a metaphor would help, draw from one of two domains: **cooking/kitchen/restaurant** or **music/orchestra/ensemble**. Pick by which next sentence carries less abstraction — kitchen for perishability and material flow, orchestra for shared-downbeat parallelism, either for sequencing.

Constraints:

- One metaphor per concept, then drop back to direct technical language. Never mix domains in one paragraph.
- Map to the concept's *role*, not its surface.
- Stay specific — "like soup" is weak; "like keeping stock simmering on a back burner" carries density.
- When the metaphor breaks, say where it breaks. Honest seam > smooth lie.
- Skip metaphor entirely when the user asks for a fix not an explanation, when the concept is trivial, or in PR review reply text.
