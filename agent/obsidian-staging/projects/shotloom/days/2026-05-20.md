# Shotloom devlog 2026-05-20

## PR 368

1. 지적 — Rust 2021 sibling module re-export는 `self::`로 qualify한다.
   Review는 `crates/shotloom-engine/src/bridge/handlers/stage/mod.rs`의
   `use boundary::...`, `use edit::...`, `use lifecycle::...`가 current
   `stage` module 기준 relative path로 resolve되지 않고 crate/external path를
   찾는다고 지적했다. Facade split은 dispatcher surface를 보존해야 하므로,
   compile failure가 나면 handler body equivalence 이전에 routing contract가
   깨진다. -> `0e9e4318`에서 sibling re-export가 `self::boundary`,
   `self::edit`, `self::lifecycle`로 qualify됐다.

2. 지적 — 같은 visibility scope는 같은 spelling으로 유지한다. Review는
   `crates/shotloom-engine/src/bridge/handlers/stage/mod.rs`의 legacy wrapper
   handlers가 `pub(in super::super)`를 쓰고, 새 dispatcher-visible re-export block은
   `pub(in crate::bridge)`를 써서 semantically same scope를 두 spellings로
   표현한다고 봤다. Visibility spelling은 grep 가능한 dispatcher surface의 일부라,
   같은 boundary를 다르게 쓰면 다음 refactor에서 drift가 재도입된다. ->
   `2c08c847`에서 `handle_set_clear_color`, `handle_set_stage_mood`,
   `handle_new_bundle_command`가 `pub(in crate::bridge)`로 정렬됐다.

> [!abstract] Rule
> Rust facade modules should make sibling imports explicit and keep dispatcher
> visibility spelling uniform. Compile-time path resolution and grep-friendly
> ownership boundaries are part of the refactor contract. #rule
