# Pi 트리 구조(Tree Structure) 워크플로우 꿀팁

`pi` 터미널 코딩 에이전트의 가장 강력한 무기인 **"트리 기반 컨텍스트 관리"**를 200% 활용하기 위한 3가지 방법론과 단축키 정리입니다. 기존의 선형적인 챗봇 형태와 달리, `pi`는 대화 이력을 트리(Tree)로 분기하며 관리합니다.

## 핵심 방법론 3가지

### 1. 세이브 로드 (Save Scumming) 기법과 북마크
* **언제:** 대규모 리팩토링, 위험한 파일 수정, 꼬일 가능성이 높은 작업 직전
* **방법:** 트리 뷰(`/tree`)를 열고 `Shift+L`을 눌러 현재 시점에 북마크(라벨)를 지정합니다. (예: "라우터 마이그레이션 시작")
* **효과:** 에이전트가 코드를 망치거나 엉뚱한 방향으로 진행할 때, 굳이 말로 수정하라고 지시할 필요가 없습니다. 즉시 북마크 지점으로 돌아가서 깨끗한 상태로 다시 시작하면 됩니다.

### 2. 평행 우주 실험 (A/B Testing Prompts)
* **언제:** 에이전트가 오답을 내거나 원하지 않는 라이브러리를 사용하려고 할 때
* **방법:** "그 라이브러리 쓰지 마"라고 이어 말하지 마세요. (컨텍스트만 낭비됨) `Esc` 두 번을 눌러 트리를 열고 **내가 질문했던 바로 그 시점(분기점)**으로 점프한 뒤 프롬프트를 보강해서 다시 질문합니다.
* **효과:** 실패한 시도의 쓰레기 토큰이 컨텍스트에 쌓이는 것을 막아주어, 모델의 퍼포먼스와 응답 정확도를 극대화합니다.

### 3. 황금 루트 가지치기 (Golden Path Cloning)
* **언제:** 여러 번의 분기를 통해 드디어 정답 루트를 완성했지만 세션 트리가 너무 무거워졌을 때
* **방법:** 작업이 성공한 마지막 시점에서 명령어 `/clone`을 실행합니다.
* **효과:** 그동안 시도했던 잡다한 브랜치들은 모두 버리고, 오직 처음부터 끝까지 **"성공한 흐름"만 일자로 추출**하여 새로운 깨끗한 세션 파일을 만들어 줍니다. 가장 깔끔한 기억 정리 기법입니다.

## 필수 트리 단축키 마스터

트리 뷰에 진입하면 마우스 없이 다음 단축키로 제어해야 합니다:

* **`Esc` 타닥 (두 번)**: 빠른 트리 뷰 진입 (`/tree` 타이핑 생략)
* **`Ctrl + O` (모드 필터링)**: 트리 뷰에서 이 단축키를 누르면 필터가 바뀝니다. 에이전트가 `bash`나 `read`로 툴을 너무 많이 썼을 때 **`no-tools` 모드**로 변경하면 대화 흐름만 깔끔하게 보입니다.
* **`Alt + ← / →`**: 여러 개로 갈라진 브랜치를 좌우로 넘나들며, "1번 지시를 따랐을 때의 결과"와 "2번 지시를 따랐을 때의 결과"를 손쉽게 비교할 수 있습니다.
* **`/fork` 명령어**: `/clone`이 현재까지의 전체를 복사한다면, `/fork`는 과거의 **특정 질문 하나를 콕 집어** 그 시점부터 새 세션을 파주는 파워 툴입니다.
