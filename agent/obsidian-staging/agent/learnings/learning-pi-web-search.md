# Pi 웹 검색(Web Search) 및 브라우저 도구 활용법

일반적인 터미널 기반 LLM 에이전트(Claude Code, Codex 등)는 로컬 파일 시스템(`bash`, `ls`, `grep`)에만 접근할 수 있으며 인터넷 검색 기능이 내장되어 있지 않습니다. 하지만 `pi` 환경에서는 공식 `pi-skills` 확장을 통해 강력한 웹 검색과 브라우저 제어가 가능합니다.

## 사용 가능한 두 가지 강력한 웹 툴

### 1. `brave-search` (빠른 정보 검색)
* **특징:** 브라우저를 띄우지 않고 Brave Search API를 이용해 빠르고 가볍게 웹을 검색하고 페이지 내용을 텍스트로 추출합니다.
* **용도:** 최신 공식 문서(Docs) 검색, 에러 코드 구글링, 최신 라이브러리 문법 확인 등.

### 2. `browser-tools` (복잡한 브라우저 제어)
* **특징:** 실제 Chrome(CDP) 브라우저를 백그라운드에서 실행하여 화면 렌더링, 클릭, 스크롤, 심지어 **스크린샷 캡처**까지 지원합니다.
* **용도:** SPA(Single Page Application) 크롤링, 로그인이 필요한 사내망/웹페이지 확인, 프론트엔드 UI 렌더링 결과(스크린샷) 확인.

## 에이전트 인지 규칙 (pi-behavior.md)

에이전트가 "저는 인터넷에 접속할 수 없습니다"라고 대답하는 멍청한 상황을 방지하기 위해, `~/.pi/agent/rules/pi-behavior.md`에 다음 규칙을 강제해 두었습니다.

> **Web Search Routing:** 사용자가 "웹을 검색해줘", "문서를 찾아줘"라고 요청하면 인터넷 연결이 없다고 변명하지 말고 즉각 `brave-search` 툴을 사용할 것. 복잡한 상호작용이나 캡처가 필요하면 `browser-tools`를 사용할 것.

**활용 꿀팁:** 코딩을 하다가 모르는 API나 라이브러리 변경점이 생기면, 에이전트에게 주저하지 말고 *"Brave Search로 XX 라이브러리 19버전 변경점 찾아서 적용해줘"* 라고 지시하면 됩니다.
