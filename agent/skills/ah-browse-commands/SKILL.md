# ah-browse-commands

Web-based browser for commands stored in `agent/commands/`.

## Purpose

Provide a web UI to browse and view all registered commands with their descriptions and metadata.

---

## Features

- List all registered commands
- View command descriptions and allowed tools
- Display argument hints (`<required>` / `[optional]`)
- Quick reference for slash commands

## Usage

Access via skill-server dashboard or directly at `/skills/commands-browser`.

## Files

- `index.html` - Commands browser page
