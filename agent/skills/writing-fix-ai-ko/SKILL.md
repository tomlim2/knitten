# writing-fix-ai-ko

한국어 텍스트에서 AI가 쓴 티를 빼는 에디터. 영어 AI 패턴(writing-fix-ai)과 별개로, 한국어 특유의 번역체·과장·수동태 패턴을 잡는다.

## 작업 순서

1. 입력 텍스트에서 아래 20가지 패턴을 스캔
2. 해당 부분을 자연스러운 한국어로 다시 씀
3. 원래 뜻은 유지
4. 문체 톤(격식/비격식/기술문서)은 맥락에 맞춤

---

## 20가지 한국어 AI 패턴

### 내용 패턴 (1-5)

**1. 과장된 중요성 부풀리기**
- 감시 단어: 핵심적인, 필수적인, 획기적인, 혁신적인, 중추적인, 결정적인, 선도적인
- 문제: 별거 아닌 것도 "핵심적인 역할을 수행" 같은 표현으로 뻥튀기
- 전: "이 시스템은 프로젝트의 핵심적인 역할을 수행하며 혁신적인 변화를 이끌었습니다"
- 후: "이 시스템으로 로드 타임을 30초에서 6초로 줄였다"

**2. "~를 통해" 남발**
- 감시 단어: ~를 통해, ~를 활용하여, ~를 기반으로, ~를 바탕으로
- 문제: 영어 "through/by/based on"의 직역. 한국어는 그냥 조사로 충분
- 전: "Python 스크립트를 활용하여 텍스처 해상도 상한을 설정하는 작업을 수행했습니다"
- 후: "Python 스크립트로 텍스처 해상도 상한을 걸었다"

**3. "다양한/효율적인/체계적인" 삼총사**
- 감시 단어: 다양한, 효율적인, 체계적인, 종합적인, 전략적인, 유기적인, 능동적인
- 문제: 구체적인 내용 없이 형용사로 고급스러워 보이려는 패턴
- 전: "다양한 플랫폼에 맞춰 효율적인 광고를 체계적으로 제작"
- 후: "Instagram, YouTube, Facebook 광고를 만들었다"

**4. "Not A but B" 번역체**
- 감시 단어: 단순한 A가 아니라 B, A를 넘어 B, A에 그치지 않고 B
- 문제: 영어 "Not just A but B"의 직역. 한국어에서는 어색
- 전: "단순한 도구가 아니라 파이프라인 전체를 바꾸는 시스템이었습니다"
- 후: "이 도구로 파이프라인 전체가 바뀌었다"

**5. 모호한 근거 제시**
- 감시 단어: ~에 기여, ~을 실현, ~을 도모, 이를 통해 ~이 가능해졌습니다
- 문제: 뭘 했는지 안 나오고 "기여했습니다"로 끝남
- 전: "프로젝트 최적화에 기여하여 팀 생산성 향상을 실현했습니다"
- 후: "프로젝트를 700GB에서 400GB로 줄였다"

### 문법 패턴 (6-10)

**6. 수동태/사역 과다**
- 감시 단어: ~되었습니다, ~시켰습니다, ~이 이루어졌습니다, ~이 수행되었습니다
- 문제: 누가 했는지 안 나옴. 영어 passive voice 직역
- 전: "캐릭터 로드 시스템의 최적화가 수행되었습니다"
- 후: "캐릭터 로드 시스템을 최적화했다"

**7. "~에 대한/~에 대해" 남용**
- 문제: 영어 "about/regarding"의 직역. 한국어는 직접 붙이면 됨
- 전: "셰이더 시스템에 대한 개선 작업을 진행했습니다"
- 후: "셰이더 시스템을 개선했다"

**8. 명사화 과다 (동사를 명사로)**
- 감시 단어: ~의 구현, ~의 설계, ~의 개발, ~의 최적화, ~작업을 수행
- 문제: "구현했다"면 될 걸 "구현을 수행했습니다"로 늘림
- 전: "Git 마이그레이션의 리드를 담당하며 브랜치 전략의 설계를 수행"
- 후: "Git 마이그레이션을 리드하고 브랜치 전략을 짰다"

**9. 조사 과잉**
- 감시 단어: ~에 있어서, ~에 관한, ~에 의한, ~로부터의
- 문제: 일본어/영어 문법의 한국어 이식
- 전: "성능 최적화에 있어서 텍스처 해상도에 관한 상한 설정을 진행"
- 후: "텍스처 해상도 상한을 걸어서 성능을 올렸다"

**10. "~하는 것이 가능합니다" 우회**
- 감시 단어: ~이 가능합니다, ~할 수 있게 되었습니다, ~이 실현되었습니다
- 문제: "할 수 있다"면 될 걸 돌려 말함
- 전: "코드 수정 없이 프리셋 추가가 가능합니다"
- 후: "코드 수정 없이 프리셋을 추가할 수 있다"

### 문체 패턴 (11-15)

**11. 균일한 문장 길이**
- 문제: 모든 문장이 비슷한 길이. 짧은 문장이 없음
- 해결: 긴 문장 사이에 짧은 문장을 섞는다. "6초로 줄였다." 같은 한 마디

**12. "~며, ~고, ~하여" 연쇄**
- 문제: 한 문장에 절이 3~4개 이어지면서 끝이 안 남
- 전: "시스템을 설계하고, 구현하며, 테스트를 진행하고, 배포하였습니다"
- 후: "시스템을 설계하고 구현했다. 테스트 후 배포."

**13. 격식체 통일 강박**
- 문제: 전부 "~습니다/~입니다"로 끝남. 실제 한국어는 톤이 섞임
- 해결: 맥락에 따라 "~했다", "~이다", "~됐다"를 섞어 쓴다

**14. 나열식 설명 (볼드 + 콜론)**
- 문제: "**항목**: 설명" 형태의 기계적 나열
- 해결: 문장 안에 자연스럽게 녹이거나, 나열이 필요하면 구조를 바꾼다

**15. 접속사 과다**
- 감시 단어: 또한, 더불어, 나아가, 이에 따라, 이를 기반으로, 궁극적으로
- 문제: 문장마다 접속사로 시작. 영어 "Additionally/Furthermore" 직역
- 해결: 접속사 없이 바로 다음 문장을 시작

### 커뮤니케이션 패턴 (16-18)

**16. 아첨/과찬**
- 감시 단어: 훌륭한 질문입니다, 정말 좋은 포인트, 핵심을 찌르셨네요
- 문제: RLHF 학습의 부산물. 사람은 이렇게 안 말함

**17. 마무리 훈계**
- 감시 단어: ~하는 것이 중요합니다, ~해야 할 것입니다, ~이 필요합니다
- 문제: 안 물어본 조언을 끝에 붙이는 습관
- 전: "텍스처 최적화를 통해 성능 개선이 이루어졌으며, 향후에도 지속적인 관리가 필요합니다"
- 후: "텍스처를 최적화해서 성능이 올랐다"

**18. 후속 질문 강제**
- 감시 단어: ~에 대해 더 알고 싶으시면, 추가 정보가 필요하시면, 더 자세히 설명해 드릴까요?
- 문제: 글에 챗봇 찌꺼기가 남아있음

### 필러/헷지 (19-20)

**19. 필러 표현**
- 전/후:
  - "~을 위해서" → "~하려고"
  - "~라는 사실은" → 삭제
  - "~라고 할 수 있습니다" → "~이다"
  - "~의 경우에는" → "~은"
  - "~하는 과정에서" → "~할 때"

**20. 과도한 헷지**
- 감시 단어: 어느 정도, 일정 부분, 상당한, 비교적, ~라고 볼 수 있습니다
- 문제: 확실한 사실도 불확실하게 표현
- 전: "이 최적화는 상당한 수준의 성능 개선을 가져왔다고 볼 수 있습니다"
- 후: "이 최적화로 GPU 3.5ms를 줄였다"

## 톤 유지 원칙

- 기술 문서 → "~했다" 체, 간결하게
- 이력서/포폴 → 사실 위주, 숫자 살리기
- 블로그/SNS → 말하듯 쓰기, 짧은 문장 위주
- 비즈니스 문서 → "~합니다" 허용하되 과잉 수동태 제거

## 출력

1. 수정된 텍스트
2. 주요 변경 요약 (선택)
