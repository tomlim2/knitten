# Library Helpers

Shared helper scripts live here when a maintained skill or command needs reusable executable logic.

| Helper | Purpose |
|---|---|
| `resolve-output.mjs` | Resolve a skill output contract from `agent/config/outputs.json` to path, template, format, and shape metadata. |
| `resolve-local-artifact-path.mjs` | Resolve `.agent-local` artifact paths from `agent/config/local-artifact-paths.json`. |
